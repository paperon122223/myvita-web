Propuesta de valor
Sistema integrado que cierra el ciclo de verificación

A diferencia de apps de recordatorio, MyVita verifica físicamente la apertura del compartimento correcto y notifica con evidencia objetiva.

💊

Pastillero IoT inteligente

Dispensador circular de 8 compartimentos impreso en 3D. El servomotor gira al compartimento indicado, el buzzer emite señal sonora y el sensor óptico detecta la apertura vía BLE.

📱

Aplicación móvil Android

Apache Cordova con SQLite offline-first + sincronización Supabase. Compatible con Android 8.0 a 14.0, cubriendo más del 90% del mercado nacional.

🤖

Asistente IA conversacional

API de GROQ con modelo LLaMA 3.1 para consultas sobre medicamentos, interacciones y tratamientos. Orientación médica disponible en todo momento.

📷

Escaneo OCR de recetas

Tesseract.js extrae automáticamente medicamento, dosis y frecuencia desde fotografías de recetas médicas. Reduce errores de captura manual.

🗺️

Mapa de farmacias y clínicas

MapTiler sobre OpenStreetMap localiza servicios de salud cercanos con soporte offline para zonas rurales con conectividad intermitente.

🚨

Botón SOS con ubicación

En emergencias envía coordenadas GPS a contactos por SMS y WhatsApp. Respaldo crítico para adultos mayores que viven solos.

👤

Modo cuidador en tiempo real

Vinculación por código de 6 dígitos. El cuidador recibe alertas automáticas cuando el pastillero no se abre a la hora programada.

📡

Arquitectura offline-first

Diseñada para zonas rurales con conectividad intermitente. Almacenamiento local con sincronización automática cuando hay internet.
